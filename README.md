# Party

Astro website with a static public frontend and a Supabase-ready staff platform backend.

## Commands

```bash
pnpm install
pnpm dev
pnpm build
pnpm preview
```

The staff directory currently uses validated fixture data, so normal Astro development does not require a local backend or an `.env` file. See [docs/staff-platform.md](docs/staff-platform.md) for the architecture, local Supabase workflow, deployment steps, and remaining development order.
